# Otpusk project instructions

Maintain `DECISION_LOG.md` as the project's ongoing, downloadable decision journal, as requested by the user.

- Read the journal before starting project work.
- Update it when meaningful project decisions are agreed or changed.
- Keep confirmed decisions separate from proposals and assistant assumptions.
- Preserve decision history: add a replacement entry and mark the old entry as superseded instead of silently rewriting it.
- Use stable decision IDs and dated entries, following the journal's format.
- When the user requests the journal, provide a link to the current file.
