## Otpusk project status and getting started

This document belongs to the Otpusk working draft. The draft covers the main
leave-tracking criteria and can be started locally with `pnpm install` and
`pnpm dev` from the repository root. Open http://127.0.0.1:5173, sign in with a
fictional account from the project decision journal, and use Corporate documents
to browse the shared library. Use `pnpm build` and `pnpm start` for a built local
preview.

Email reminders, corporate events, parties, private medical certificates,
employment contracts, financial transparency, and integrations with Teams, Jira,
banking, and other company tools are planned next. They remain outside this draft
because production accounts, financial information, cloud connections, and
corporate-mandatory workflows require additional security and product decisions.
